# 🕹️ Game Jam Project (Multi-Machine / Multi-AI)

Projeto preparado para ser desenvolvido colaborativamente por múltiplos desenvolvedores e Assistentes de IA simultaneamente durante uma Game Jam.

## 📂 Estrutura de Documentação Central

- [GEMINI.md](file:///c:/Users/26012195/Documents/Game%20Jeam%2028-09-2026/GEMINI.md): **Guia essencial para IAs** (instruções de código em Godot 4, convenções, padrão de arquitetura modular para evitar conflitos de merge e regras de coordenação).
- [PROJECT_STATE.md](file:///c:/Users/26012195/Documents/Game%20Jeam%2028-09-2026/PROJECT_STATE.md): **Dashboard de estado vivo** (tarefas pendentes, em andamento, concluídas e módulo por máquina).

## 🚀 Como Iniciar

1. Certifique-se de que a engine **Godot 4** está instalada.
2. Cada máquina/IA deve ler o arquivo [GEMINI.md](file:///c:/Users/26012195/Documents/Game%20Jeam%2028-09-2026/GEMINI.md) antes de começar.
3. Consulte o [PROJECT_STATE.md](file:///c:/Users/26012195/Documents/Game%20Jeam%2028-09-2026/PROJECT_STATE.md) para escolher uma tarefa livre e registrar que está trabalhando nela.
4. Faça `git pull` com frequência e mantenha commits granulares.
